# IMDb Movie Rating Scraper 🎬

A Python-based web scraping and data analysis mini project that collects movie information from IMDb using Selenium.

## 📌 Project Description

The **IMDb Movie Rating Scraper** automatically collects movie details from IMDb and stores the collected data in a CSV file.

The project also provides different options to search, filter, analyze, and visualize the movie data.

## 🎯 Objectives

* Automate movie data collection from IMDb
* Reduce manual effort
* Store movie data in CSV format
* Search and filter movies
* Analyze movie ratings
* Visualize movie data using graphs

## 📊 Data Collected

The project collects:

* Movie Rank
* Movie Title
* Release Year
* IMDb Rating

## 🛠️ Technologies Used

* **Python** – Main programming language
* **Selenium** – Web scraping and browser automation
* **Chrome WebDriver** – Controls Google Chrome
* **Pandas** – Data processing and analysis
* **Matplotlib** – Data visualization
* **CSV** – Data storage

## ✨ Features

### 🔍 Movie Search

Search for a movie by entering its title.

### ⭐ Rating Filter

Display movies based on a minimum IMDb rating.

### 🏆 Highest Rated Movie

Find the movie with the highest IMDb rating.

### 🔟 Top 10 Movies

Display the top 10 movies based on IMDb rating.

### 📅 Year Explorer

Find movies released in a particular year.

### 📈 Rating Statistics

Display:

* Average Rating
* Highest Rating
* Lowest Rating
* Total Movies

### 📊 Data Visualization

The project includes:

* Rating Distribution
* Top 10 Movies Chart
* Year-wise Movie Count
* Average Rating by Year

## ⚙️ Installation

Install the required Python libraries:

```bash
pip install pandas matplotlib selenium webdriver-manager
```

## ▶️ How to Run

Run the Python program:

```bash
python main.py
```

The program will load the movie data from `movies.csv` and display the menu.
